## 功能上能做什么

简单说几个日常最用得上的地方：

**树状节点管理**：支持同时连接多个服务器，用标签页来区分不同项目，节点以树状结构展示，层级一眼看清楚，做增删改查也很直观。

**实时状态仪表盘**：内置仪表盘，可视化展示 ZooKeeper 服务的健康指标，包括每秒流入流出字节数、延迟、排队请求数量等，用来做集群维护或者排查异常特别顺手。

**多格式数据自动格式化**：节点值自动识别并格式化 Text、JSON、XML、HEX、MessagePack、Gzip、Snappy 等格式，不用手动转，看着干净多了。

**强大的搜索**：可以搜索节点路径，也可以在节点的值里做正则、整词、大小写匹配搜索，在大规模节点树里找数据不用再逐层翻了。

**命令行支持**：内置命令行，zkCli.sh 提供的命令和四字符命令都支持，习惯命令行操作的人不用切来切去。

**导入 / 导出**：快速批量导入或导出节点数据，迁移或备份的时候能省不少时间。

**GPU 渲染**：界面渲染利用 GPU，流畅度高，资源占用相对较低。
